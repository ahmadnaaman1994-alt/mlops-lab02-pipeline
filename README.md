# ML-конвейер для прогнозирования заказов в ресторане

В этом проекте реализован ML-конвейер для лабораторной работы по дисциплине АМО.

Проект включает четыре этапа:

1. Генерация синтетических данных о заказах в ресторане
2. Предобработка данных
3. Обучение модели Linear Regression
4. Тестирование модели и расчёт метрики MAE

---

## Запуск через Docker

Конвейер состоит из трёх контейнеров, которые используют общий Docker volume (`data`) для передачи данных между этапами.

### 1. Сборка образов

```bash
docker build -f Dockerfile.create -t p6-z1 .
docker build -f Dockerfile.train  -t p6-z2 .
docker build -f Dockerfile.predict -t p6-z3 .
```

### 2. Запуск контейнеров (по порядку)

Контейнеры необходимо запускать последовательно — каждый следующий зависит от результатов предыдущего.

#### Шаг 1 — генерация данных

```bash
docker run --name z1 -v data:/app p6-z1
```

#### Шаг 2 — предобработка и обучение модели

```bash
docker run --name z2 -v data:/app p6-z2
```

#### Шаг 3 — тестирование модели

```bash
docker run --name z3 -v data:/app p6-z3
```

### Примечание

Если контейнеры с такими именами уже существуют, удалите их перед повторным запуском:

```bash
docker rm z1 z2 z3
```
