# ML-конвейер для прогнозирования заказов в ресторане

Этот проект демонстрирует простой конвейер машинного обучения (ML pipeline), 
который использует синтетические данные о количестве заказов в ресторане в течение дня.

Цель проекта — показать, как можно автоматизировать рабочий процесс машинного обучения 
с помощью нескольких Python-скриптов, объединённых в один конвейер.

## Идея проекта

Набор данных моделирует количество заказов в ресторане в зависимости от часа дня.

В данных присутствуют два пика:
- время обеда
- время ужина

Данные для обучения более «чистые», а тестовые данные содержат шум и аномалии, 
чтобы проверить устойчивость модели.

## Этапы конвейера

Конвейер состоит из четырёх этапов:

1. **Создание данных**
   - Генерация синтетических данных о заказах
   - Сохранение данных в папках `train` и `test`

2. **Предобработка данных**
   - Масштабирование признаков с помощью `StandardScaler`

3. **Обучение модели**
   - Обучение модели Linear Regression на обучающих данных

4. **Тестирование модели**
   - Проверка модели на тестовых данных
   - Расчёт метрики MAE (Mean Absolute Error)
