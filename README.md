# ML-конвейер для прогнозирования заказов в ресторане

В этом проекте реализован простой ML-конвейер для лабораторной работы по дисциплине АМО.

Проект включает четыре этапа:
1. генерация синтетических данных о заказах в ресторане
2. предобработка данных
3. обучение модели Linear Regression
4. тестирование модели и расчёт метрики MAE

Все этапы объединены в автоматический pipeline.

Запуск конвейера:

Windows
pipeline.bat

Linux / Mac
bash pipeline.sh
